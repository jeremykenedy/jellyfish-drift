# Architecture

The unreleased 1.1 candidate replaces the Canvas bitmap mesh with an OpenGL ES 2 renderer. Jellyfish bells are curved triangle surfaces. Separate oral-arm ribbons and fine marginal tentacles are attached beneath each bell. Vertex shaders change bell breadth and height during contraction, propagate delayed motion down the appendages, and rotate each animal in three dimensions. The renderer does not draw the old specimen images as cards.

The material approximates translucent gelatin with view-dependent edges, broad tissue scattering, local highlights, radial canals, smaller capillary detail and internal horseshoe-shaped tissue for the moon species. Fine surface color comes from small tissue regions of the existing original artwork mapped onto the curved bell. These maps do not replace the animated geometry. A minimum projected tentacle width reduces subpixel breakup on distant animals. It is an original rendered depiction, not recorded footage, a biological simulation or numerical volume rendering. Native direction is accepted for the physical gate; physical playback remains pending in [verification](VERIFICATION.md).

A separate full-screen shader supplies dark or light water, moving particles and optional overhead light. Depth, scale, rotation and independent phases distinguish animals. All six existing preference keys and accepted values remain stable. Density changes the actual number of animals; movement changes the animation clock for bodies, contractions, appendages and water effects. The species choice changes bell proportions, pigmentation and appendage length.

Both PreviewActivity and JellyfishDreamService use the same GLSurfaceView. The owning lifecycle resumes its rendering thread while visible and pauses it when stopped. Context recreation rebuilds shader programs; a shader link or compile error fails visibly instead of silently substituting a still image. The intended frame interval is approximately 33 milliseconds. Actual frame pacing, heat and power require physical measurement and are not established by this interval.

The application requests no network permissions, adds no third-party runtime dependencies and bundles its shaders, NOTICE and full license. Credits are readable offline from native settings. Production signing credentials remain outside the repository. Geometry construction, option resolution and provider value validation are pure Java and covered by host tests. Android lifecycle, graphics, shader output and remote navigation require native validation.
