# Jellyfish Drift 3.0.0

This release restores the original illustrated Jellyfish Drift scene and its six controls. Filmed Blue aquarium and Deep ocean move to a separately installed Jellyfish Drift V2 app. Version 3 is a major change from the filmed version 2, with a higher Android code so the original package can update while retaining its data.

## Upgrade guide

Users of versions 1.0.0 and 2.0.0 update the existing package normally. Android 6.0/API 23 remains the minimum. Android code 7 is newer than previous private and public codes 1 through 6. Keep the app installed and run `python3 install.py --serial TV_IP:5555` against the verified published release. No data clear, uninstall, database migration, environment change, cache clear, or worker restart is required.

The original package, signing identity, Dream component, provider authority, and six saved values remain stable. Open native settings and recheck background, amount, movement, species, lighting, and randomization: all six affect the classic scene again. Installing an update does not select a different Dream or change timers.

To use the filmed scenes, install Jellyfish Drift V2 separately and select its Dream. Classic and V2 do not share preferences. Returning to classic means selecting its existing Dream. A signed APK downgrade is not promised; uninstalling deletes app data. Keep important preference values before removing either app.

## Breaking changes

| Version 2 | Version 3 | Action |
| --- | --- | --- |
| Filmed recordings in the original package | Original Canvas jellyfish scene restored | Install the separate V2 app for filmed scenes |
| Only scene, playback speed, and randomization effective | All six original visual controls effective | Recheck saved amount, species, and rays |
| Playback speed at 0.9x, 1x, 1.25x | Original simulated movement speeds | Choose movement in native settings |

## Major changes

The restored scene and original artwork come from the public v1.0.0 source. Dark/light water, configurable amounts and species, rays, speed, and random selections return. This is the classic illustrated renderer, not a claim of realistic filmed animals.

## Minor changes and fixes

An optional local-time clock is off by default and slowly drifts when enabled. It keeps the saved on/off choice through scene randomization. The original production signer is retained. Provider updates acknowledge committed saves. Native settings include full offline Apache notices and initial Preview focus. The actual pure settings classes retain full coverage gates, including safe handling of invalid stored choices.

## Verification and limits

Code 7 passes local settings/installer tests, formatter, and full pure-Java coverage, including display-cadence regression tests. Code 6 passed native controls, clock independence and drift, same-signer legacy retention, Credits, and normal physical Dreams, but its measured 20.00 and 20.66 FPS failed the release gate. Code 7 changes scheduling to a vsync-based 30 FPS cap while keeping elapsed-time motion and the original artwork. The exact code 7 candidate then passed native controls, seven-value retention, Preview/Home/resume and two actual normal Dreams. Minimum sampled app-layer presentation rates were 29.9987 OFF and 30.4872 ON; clock ON includes separate overlay redraws. Three settled buffers per preset were sampled without screenrecord, not a continuous full-duration trace. Surrounding state was restored exactly. Browser, verified remote-primary, and public-download gates remain pending before publication. Native 4K, sustained thermal behavior, physical Google TV, and owner visual acceptance are not claimed.
