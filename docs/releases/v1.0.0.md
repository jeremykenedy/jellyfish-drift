# Jellyfish Drift 1.0.0

First stable release of the animated jellyfish screensaver.

## Included

- Three original jellyfish species, deep-water and bright-water scenes, and animated swimming.
- Density and movement controls, optional top-down sunlight, and per-setting or all-setting random selection.
- A D-pad settings screen, an Android DreamService, and a settings provider for host applications.
- An ADB installer and explicit uninstall command.
- No ads, analytics, telemetry, crash reporting, tracking, network permission, or runtime network requests.

## Compatibility

Android 6.0 (API 23) or later with DreamService support. The release was tested on a Fire TV (AFTDEC012E, Fire OS 11/API 30) and an Android TV emulator. The emulator and Fire TV checks are documented in [device verification](../VERIFICATION.md). A physical Google TV device was not available for verification.

## Install

Connect the TV with ADB and run the installer to download and verify the latest release automatically:

```bash
python3 install.py --serial TV_IP:5555
```

For a manual install, download `jellyfish-drift.apk` and `jellyfish-drift.apk.sha256` from the release and verify the checksum with:

```bash
shasum -a 256 -c jellyfish-drift.apk.sha256
```

Install with the documented [ADB installer](../INSTALLATION.md), then select Jellyfish Drift in the TV's screensaver settings. The installer does not change the current screensaver selection or system timers.

## Upgrade path

There is no earlier public version to upgrade. This release installs as a fresh app. Future APK updates must keep the same package name and signing certificate; install an update without uninstalling to preserve local settings.

## Changes

No breaking changes. This is the first public release and establishes package version `1.0.0` and Android version code `1`.
